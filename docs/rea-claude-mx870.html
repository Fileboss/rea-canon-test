Rétro-ingénierie assistée par IA · Claude × REA

Redonner vie à une imprimante de 2009 sur Mac Apple Silicon

Canon ne fournit aucun pilote pour la PIXMA MX870 sur les Mac récents. Claude, un assistant IA, a étudié le pilote Windows avec l'outil REA pour comprendre la « langue » de l'imprimante, puis a écrit un pilote moderne à partir de ce qu'il a découvert.

Le point de départ

Pourquoi ce projet ?

01

Aucun pilote officiel

Canon ne propose qu'un pilote Windows 32 bits. Rien pour les puces Apple M1 à M5.

02

Des alternatives incomplètes

Les solutions génériques n'exposent pas toutes les fonctions, et Gutenprint (pilote libre) est déprécié sur Homebrew, avec des couleurs parfois inversées.

03

Un but pédagogique

Découvrir la rétro-ingénierie : comprendre un logiciel sans son code source, en observant le programme livré.

La méthode

Six étapes, de l'installeur au pilote

La rétro-ingénierie consiste à lire un programme compilé (illisible pour un humain) et à le retraduire en un pseudo-code compréhensible, afin d'en déduire son fonctionnement.

Ouvrir l'installeur REA

REA reconnaît un WinZip Self-Extractor : un programme qui contient une archive. On en extrait 445 fichiers, dont des archives CAB qui renferment le vrai pilote.

Identifier les pièces Claude

En lisant le fichier d'installation et en suivant qui appelle qui, Claude repère les 4 modules qui comptent sur une centaine. Certains ne contiennent que des données : tables de couleurs et motifs de tramage.

Décompiler et chercher REA + Ghidra

REA pilote le décompilateur Ghidra. Plus de 2 300 fonctions sont retraduites en pseudo-code, puis Claude y cherche des indices : chaînes de texte, octets caractéristiques, appels réseau.

Recouper les sources Claude

Chaque déduction est comparée à Gutenprint, un pilote libre pour des modèles proches. Les codes de formats et de supports coïncident, ce qui confirme la lecture.

Reconstruire Claude

Le pilote est réécrit de zéro en C, nativement pour Apple Silicon. Les tableaux de réglages sont extraits automatiquement des données Canon, ce qui évite les erreurs de recopie.

Vérifier sans imprimante Humain + Claude

Un décodeur indépendant relit chaque flux produit et redessine la page ; un simulateur imite l'imprimante sur le réseau. Ces tests ont révélé, puis fait corriger, plusieurs bugs réels.

Découvertes clés

Ce que REA a permis de comprendre

Le langage

Des commandes courtes et une enveloppe

L'imprimante reçoit une suite de commandes de la forme « ESC ( lettre, longueur, données » : résolution, papier, encres… le tout précédé d'un petit message XML d'ouverture.

ESC (d 02 58 02 58 → 600 × 600 points par pouce
La compression

L'image découpée en bandes

La page est envoyée par bandes de 16 lignes, une par encre. Chaque ligne est compressée (PackBits : « répète cet octet 50 fois ») et se termine par un marqueur.

L'astuce

5 points dans un seul octet

Pour les encres à 3 niveaux (rien, petit point, gros point), 5 points tiennent dans un octet car 35 = 243 < 256. Vérifié sur les 243 combinaisons de la table Canon.

octet = p₀×81 + p₁×27 + p₂×9 + p₃×3 + p₄
Les réglages

30 modes et 21 formats exacts

Chaque couple papier × qualité correspond à un réglage d'encres précis. Les dimensions de papier sont au 1/600ᵉ de pouce près : l'imprimante s'en sert pour choisir le bac.

Le réseau

Le protocole BJNP de Canon

Ouverture d'une session, envoi par paquets dont chacun est accusé, attente de 500 ms si l'imprimante est occupée (abandon après 10 s), puis fermeture.

Les deux noirs

Noir texte et noir photo

La MX870 a deux encres noires : une pigmentée pour le texte net sur papier ordinaire, une à colorant pour les photos. Les réglages Windows désactivent la première sur papier photo.

Le résultat

Deux façons d'imprimer depuis un Mac

Livrable 1

Pilote CUPS classique

S'installe comme un pilote traditionnel : toutes les options (papier, qualité, sans marges, recto-verso) apparaissent dans la fenêtre d'impression du Mac.

Livrable 2

Application AirPrint

Une petite application fait passer la MX870 pour une imprimante AirPrint moderne : le Mac l'utilise sans pilote, une approche durable vu l'évolution de macOS.

Où en est-on

Prêt, mais pas encore imprimé

Tout fonctionne dans les simulations : les flux produits sont relus correctement et le réseau est testé contre une imprimante simulée. Seul un essai réel dira si l'imprimante accepte tout, à commencer par une page de brouillon en noir pour limiter l'encre.

Petit glossaire

Les mots du projet

Rétro-ingénierie
Comprendre un logiciel à partir du programme livré, sans son code source.
Décompiler
Retraduire le code machine en un pseudo-code lisible par un humain.
REA
« Reverse Engineer Anything » : boîte à outils qui permet à Claude d'inspecter des programmes et de piloter Ghidra.
Ghidra
Décompilateur libre publié par la NSA, utilisé ici en arrière-plan.
Pilote
Logiciel qui traduit un document en instructions compréhensibles par une imprimante donnée.
Tramage
Imiter des nuances avec seulement quelques tailles de points d'encre.
CUPS / AirPrint
Le système d'impression du Mac / la norme d'Apple pour imprimer sans pilote.
BJNP
Le protocole réseau propriétaire des imprimantes Canon.
Projet personnel d'interopérabilité. Le pilote Windows d'origine n'est pas redistribué. Détails techniques : docs/protocole-mx870.md.
